# Reading guide for review materials

1. Read the [executive summary](executive-summary.md) for the findings and limits.
2. Review [matters and questions](matters-for-sec-review.md) and [the 2018 order cross-reference](relationship-to-2018-order.md) to separate existing findings from unanswered questions.
3. Use the [bilingual matter summaries](../cases/README.md) and [matter-to-source map](../evidence/matter-source-map.csv) to trace each item.
4. Consult the [evidence guide](../evidence/README.md): the main index is selective; the supplementary register includes background, leads and missing records. Neither is a list of exhibits held.
5. Read the separate [Shanghai residential project materials](../projects/README.md) and [outstanding-records list](../research/outstanding-records.en.md).
6. Check [methodology and limitations](../methodology/evidence-and-translation.md) and the [repository audit](../methodology/repository-audit.md) before relying on the package.

This directory contains review materials, not an SEC filing receipt or evidence that anything has been transmitted. External source artifacts are not bundled. A private repository link requires suitable reviewer access; downloaded archives preserve the relative file links.
