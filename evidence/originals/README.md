# External Originals: Availability

No external judicial or regulatory original files are bundled in this edition. The source register links to issuing-body records and other sources and identifies unavailable originals.

“Original Chinese research” elsewhere in the repository means the user's preserved research note, not a court original. Do not treat missing Wuhan, Yiwu or Jin Yun judgments, the Hunan attachment, or the leadership screenshot as attached exhibits.

If an original is added later, record its source URL, acquisition date, file name and SHA-256, and distinguish it from OCR or a reproduction. [Source register](../index.csv).
