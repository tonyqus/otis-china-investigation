# External Originals: Availability

No external judicial or regulatory original files are bundled in this edition. The [main index](../index.csv) links selected sources; the [supplementary register](../supplementary-register.csv) identifies other citations and outstanding originals. Neither register is an inventory of downloaded exhibits.

“Original Chinese research” elsewhere in the repository means the user's preserved research note, not a court original. Do not treat missing Wuhan, Yiwu or Jin Yun judgments, the Hunan attachment, or the leadership screenshot as attached exhibits.

If an original is added later, record its source URL, acquisition date, file name and SHA-256, and distinguish it from OCR or a reproduction. [Evidence guide](../README.md).
