# Evidence navigation

The [main index](index.csv) contains six selected source entries directly supporting or contextualizing the six historical matters. Six source entries do not mean six independent sources, six convictions, or six new cases. Related-source groups show the common enforcement action or reported matter. The index states each source's role, what it supports, and its limitations. Source content has not been newly reverified during this classification change.

The [supplementary register](supplementary-register.csv) accounts for the remaining 74 former entries by category: background, related reporting, unverified lead, comparison or unestablished link, outstanding record, owner statement, and excluded irrelevant material. The GitHub diagram tutorial (E033) is excluded as irrelevant; its former identifier remains recorded solely for traceability. Supplementary entries are not counted as core evidence.

[E080](../projects/owner-statement.md) records the owner's combined project figures for Zizhu Huating and Changli Huayuan; supporting records remain pending. E004 and E005 identify missing records, not documents held.

Original E-identifiers remain stable. [Source notes](source-notes/README.md) now contain only the six selected entries; the 74 non-core standalone pages have been removed. Their metadata remains in the supplementary register, with `record_location` pointing to the relevant research or project material. Existing links have been updated. External source artifacts are not bundled; see [originals](originals/README.md) and [translation status](translations/README.md).

The [matter-to-source map](matter-source-map.csv) connects all six historical matters and the separate residential project group to selected sources, related citations and missing records. For the full structure review, see the [repository audit](../methodology/repository-audit.md).
